### ==A1== 

```powershell
rocg@OS-20221121YMKQ:~/wvp$ docker images
REPOSITORY                  TAG                            IMAGE ID       CREATED         SIZE
gospace/gowvp               latest                         7a340fc03ecd   2 hours ago     1.01GB

这个 容器 在我本地，它的 tag 是 latest ，我想保存一份 image 备份；
```

你可以用 `docker save` 命令把镜像导出为 tar 文件进行备份：

```bash
docker save -o gospace-gowvp-latest.tar gospace/gowvp:latest
```

如果需要压缩节省空间，可以配合 `gzip`：

```bash
docker save gospace/gowvp:latest | gzip > gospace-gowvp-latest.tar.gz
```

---

**备份后恢复（供参考）：**

```bash
# 从 tar 文件加载镜像
docker load -i gospace-gowvp-latest.tar

# 如果是压缩版
gunzip -c gospace-gowvp-latest.tar.gz | docker load
```

备份文件会保存在你当前执行命令的目录下（`~/wvp`）。



### ==A2== 

```powershell
docker save -o gospace-gowvp-latest.tar gospace/gowvp:latest

我可以 将 latest 改为 20260819 吗？
```

可以，有两种改法，取决于你的需求：

---

**方式 1：只改备份文件名（最简单）**

```bash
docker save -o gospace-gowvp-20260819.tar gospace/gowvp:latest
```

这只是把导出的 tar 文件改名，**镜像本身的 tag 还是 `latest`**。

---

**方式 2：给镜像本身打个新 tag `20260819`，再备份（推荐）**

```bash
# 基于现有的 latest 镜像，创建一个 20260819 标签
docker tag gospace/gowvp:latest gospace/gowvp:20260819

# 然后用新标签导出备份
docker save -o gospace-gowvp-20260819.tar gospace/gowvp:20260819
```

这样你本地会同时存在两个 tag 指向同一个镜像：

```bash
docker images | grep gowvp
# gospace/gowvp   20260819   7a340fc03ecd   2 hours ago   1.01GB
# gospace/gowvp   latest     7a340fc03ecd   2 hours ago   1.01GB
```

以后恢复时，也可以用 `gospace/gowvp:20260819` 这个明确的版本号来引用，比 `latest` 更清晰。

---

**如果你之后想清理 `latest` 标签：**

```bash
docker rmi gospace/gowvp:latest
```

（注意：因为还有 `20260819` 指向同一个镜像，所以只会删除标签，不会删除实际的镜像层。）



### ==A3== 

```powershell
已经访问成功：http://localhost:15123/web/desktop
现在我该如何将 一个局域网内的摄像头 （192.168.1.179）加入 这个 go wvp
```

要将局域网摄像头（`192.168.1.179`）接入 GoWVP，核心思路是：**摄像头作为 GB28181 设备，主动向 GoWVP 的 SIP 服务器注册**。你需要在两侧配置对齐。

---

## 一、先确认 GoWVP 的 SIP 配置

登录 GoWVP Web 界面 `http://localhost:15123`，在**配置管理**或**接入信息**页面查看以下参数（也可以在 `configs/config.toml` 中查看/修改）：

| 参数               | 说明                                          | 示例                      |
| ------------------ | --------------------------------------------- | ------------------------- |
| **SIP 服务器 ID**  | 平台国标编号，20 位数字                       | `41010500002000000001`    |
| **SIP 服务器域**   | 通常是 ID 的前 10 位                          | `4101050000`              |
| **SIP 服务器端口** | 默认 `15060`（Docker 映射后的端口）           | `15060`                   |
| **密码**           | 注册鉴权密码                                  | `12345678` 或空（免鉴权） |
| **收流地址**       | 必须是宿主机**局域网 IP**，不能是 `127.0.0.1` | `192.168.1.xxx`           |

> ⚠️ **关键**：如果 `configs/config.toml` 中的 `WebHookIP` 或 SIP 相关 IP 还是 `127.0.0.1`，摄像头在局域网内是注册不上的。请修改为**运行 Docker 的宿主机的实际局域网 IP**（如 `192.168.1.100`），然后重启容器。

---

## 二、在摄像头（192.168.1.179）后台配置 GB28181

用浏览器访问 `http://192.168.1.179`，进入摄像头的**平台接入 / 网络配置 / 高级配置**，选择 **GB28181 接入**，填写：

| 摄像头配置项        | 填写内容                                                     |
| ------------------- | ------------------------------------------------------------ |
| **接入协议**        | GB28181 / GB/T28181-2016                                     |
| **SIP 服务器地址**  | GoWVP 宿主机的**局域网 IP**（不是 `localhost`，也不是容器 IP） |
| **SIP 服务器端口**  | `15060`                                                      |
| **SIP 服务器 ID**   | 与 GoWVP 配置中的 SIP 服务器 ID **完全一致**                 |
| **SIP 服务器域**    | 与 GoWVP 配置中的域 **完全一致**                             |
| **设备国标 ID**     | 摄像头自身的 20 位数字 ID（如 `34020000001320000001`）       |
| **SIP 用户认证 ID** | 通常与设备国标 ID 相同                                       |
| **密码**            | 与 GoWVP 配置中的密码 **完全一致**                           |
| **注册有效期**      | 默认 `3600` 秒                                               |
| **心跳周期**        | 默认 `60` 秒                                                 |

保存并**重启摄像头**（部分品牌需要重启才生效）。

---

## 三、在 GoWVP 上查看设备是否注册成功

1. 刷新 GoWVP Web 界面，进入 **国标设备** 页面。
2. 如果摄像头配置正确且网络可达，设备会自动出现在列表中，状态显示为**在线**。
3. 点击该设备的 **通道**，进入后点击 **播放**，即可看到实时画面。

---

## 四、常见问题排查

| 现象                        | 排查方向                                                     |
| --------------------------- | ------------------------------------------------------------ |
| **摄像头显示"注册失败"**    | 检查 SIP 服务器地址是否是宿主机局域网 IP；检查防火墙是否放行了 `15060` 和 `20000-20100` 端口。 |
| **设备在线，但播放黑屏**    | 进入 GoWVP 的 **快捷桌面 → ZLM 设置**，检查"国标收流默认地址"是否填的是**局域网 IP**（能被摄像头访问到）。Docker 合并版 Hook IP 可填 `127.0.0.1`，但收流地址必须是外网/局域网可达 IP。 |
| **通道数量显示不全**        | 这是设计如此，超过 4 个通道请在管理页查看，或点击"查看更多"。 |
| **老旧摄像头/大华设备黑屏** | 尝试在设备编辑中将**收流模式改为 UDP**。                     |

---

## 五、快速验证网络连通性

在运行 GoWVP 的宿主机上执行：

```bash
# 确认摄像头能访问到 GoWVP 的 SIP 端口
nc -zv 192.168.1.179 15060   # 从摄像头侧或宿主机侧测试连通性

# 查看 GoWVP 容器日志，看是否有 REGISTER 请求
docker logs <gowvp_container_id> | grep -i register
```

如果能看到摄像头的 REGISTER 请求日志，说明网络层已经通了，剩下的就是参数对齐问题。

---

**总结一下关键口诀**：摄像头填的是**宿主机局域网 IP + 15060 端口**，GoWVP 配置里的收流 IP 也必须是**局域网 IP**，两边 ID、域、密码保持一致，设备就会自动注册上来。
