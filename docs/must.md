------

## 1. 戒烟失败，不等于无法长期建设

戒烟是一个非常特殊的挑战。

它涉及：

- 生理依赖；
- 即时奖励；
- 压力调节；
- 环境触发；
- 习惯回路。

它不是简单的：

> “我没有毅力。”

很多人误解自己的失败：

“我连这个都做不到，我怎么可能坚持十年？”

但是实际上：

一个人在某个领域失败，不代表所有领域都失败。

例如：

| 有人：         | 但是，可以坚持：     |
| -------------- | -------------------- |
| 戒不了咖啡；   | 研究一个技术十年；   |
| 控制不了饮食； | 写博客十年；         |
|                | 做一个开源项目十年。 |

人的坚持能力不是一个总开关。
