## 当前 IAM 设计，我看到几个关键资产

### 1. 组织模型

```
departments
        |
        |
user_department
        |
        |
users
```

特点：

- adjacency list：

```sql
parent_id
```

保留树结构；

- ancestors：

```sql
BIGINT[]
```

用于：

- 查询祖先链
- 查询子树
- PostgreSQL GIN 加速

这个设计偏企业级，不是简单后台管理表。

------

### 2. 用户模型

```

```


扩展：

```sql

```

这个比较符合农业林业这种：

> 人员档案 + 组织关系 + 附件资料

的长期演进方向。

### 3. 菜单和权限分离

CMS = **Content Management System**

中文：

> 内容管理系统

它不是某个具体技术，而是一类业务能力。

典型 CMS 管理：

- 新闻
- 公告
- 文章
- 图片
- 视频
- Banner
- 专题

# 2. 内容编码生成

你的需求：


------

## function

```sql
CREATE OR REPLACE FUNCTION cms.next_content_code(
    p_type VARCHAR
)
RETURNS VARCHAR
LANGUAGE plpgsql
AS
$$
DECLARE
    v_num BIGINT;
BEGIN

    IF p_type = 'NOTICE' THEN

        v_num := nextval('cms.notice_code_seq');

        RETURN 'JL-TZ-' ||
               LPAD(v_num::TEXT, 6, '0');


    ELSIF p_type = 'MEDIA' THEN

        v_num := nextval('cms.media_code_seq');

        RETURN 'JL-MT-' ||
               LPAD(v_num::TEXT, 6, '0');

    ELSE

        RAISE EXCEPTION
            'Unsupported content type: %',
            p_type;

    END IF;

END;
$$;
```

# 5. 最重要：状态流转

我们冻结一下。

目前：

```

 |
 |
PUBLISHED
 |
 |
OFFLINE
```

但是需求：

> 编辑已失效通知，编辑完成后重新生效发布

所以：

实际上：

```
DRAFT
 |
 |
PUBLISHED
 |
 |
OFFLINE
 |
 |
DRAFT
 |
 |
PUBLISHED
```

也就是：

```
OFFLINE 可以编辑
```

------

状态迁移：

| 当前      | 动作 | 结果      |
| --------- | ---- | --------- |
| DRAFT     | 发布 | PUBLISHED |
| PUBLISHED | 失效 | OFFLINE   |
| OFFLINE   | 编辑 | DRAFT     |
| DRAFT     | 删除 | 删除      |
| OFFLINE   | 删除 | 删除      |

------

禁止：

```
PUBLISHED
   |
   |
 update
```

原因：

线上内容修改应该避免瞬间变化。

# 6. publish 业务逻辑

伪代码：

```java
@Transactional
public void publish(List<Long> ids){


    List<Content> list =
        mapper.selectBatchIds(ids);



    for(Content c:list){


        if(c.getStatus()
             .equals("PUBLISHED")){

            continue;
        }


        c.setStatus(
            "PUBLISHED"
        );

        mapper.updateById(c);
    }

}
```

------

# 7. offline

类似：

```java
@Transactional
public void offline(List<Long> ids){


    contents.forEach(c -> {


        if(
          c.status == PUBLISHED
        ){

            c.status =
               OFFLINE;
        }

    });

}
```
