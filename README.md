# gorogio

## 项目目的

gorogio 是一个 **Go + Gio 的最小实验场**，用于训练“可推理 GUI 世界”的能力。

- **核心目标**：学习即时模式 GUI（Immediate Mode UI）思维
- **适合人群**：Go 开发者、想理解 GUI 事件/状态循环的人
- **实验性质**：不追求控件丰富度或商业级产品，可随意重构和扩展

## Gio 哲学定位

- **名字**：Gio = Go + I/O 或 Go Immediate Mode
- **思维哲学**：每帧独立计算、状态集中、事件透明、函数化
- **设计哲学**：小核心库、函数化布局、可组合控件、实验/认知优先
- **定位**：GUI 认知训练工具，而非生产级控件库

## 快速运行

```bash
git clone git@github.com:rocwg/gorogio.git
cd gorogio
go mod tidy
go run .

##
$ go run .\examples\hello
```

### 使用说明（文字流程）

1. **运行某个案例**

```bash
cd examples/counter
go run .
```

- 每个案例有独立 `main.go`，事件循环和 UI 状态互不干扰。

1. **共享工具和状态**

- `internal/` 下的函数和状态可以被所有案例 import：

```go
import "github.com/rocwg/gorogio/internal"
```

- 避免在每个 main.go 内重复编写相同逻辑。

1. **实验流程**

- 每个案例是一个独立小程序 → 修改、运行、观察结果
- 想要测试新控件或布局 → 新建一个目录 + main.go
- 当案例成熟 → 可以考虑整合到单个实验台程序中（中期阶段）

------

### 文字版总结

- **短期**：多个案例目录，每个 main.go 独立运行 → 快速实验，学习 Immediate Mode UI
- **中期**：共享 `internal/` 工具和状态 → 保持 DRY
- **长期**：可以整合到一个“实验台”，通过切换 UI 场景统一运行

> 这样既贴近 Gio 官方风格，又方便你在 gorogio 中持续积累各种 GUI 实验。
